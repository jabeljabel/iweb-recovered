PSU Library subscribes to JAPAN KNOWLEDGE Database.

•You need to login using your psu id (use the VPN LIAS setting for off-campus access).  Ask a reference librarian for help.

•Probably the best single collection of online dictionaries.  Includes:Encyclopedia Nipponica, Kodansha Encyclopedia of Japan, Progressive Japanese-English/English-Japanese Dictionaries, Gendai Yogo No Kiso Chishiki, Nihon Jinmei Daijiten.
