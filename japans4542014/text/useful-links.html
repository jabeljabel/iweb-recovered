Rikaichan Firefox plugin or RIKAIKUN CHROME Extension

(SAFARI USERS ON A MAC CAN USE NATIVE DICTIONARY for the same effect)

Kanji is no excuse for not reading Japanese webpages if you use this. Plugin for the Firefox browser to generate pop-up definitions.

This also has a way to make your own vocabulary lists from a webpage.

Rikai.com

Kanji is no excuse for not reading Japanese webpages if you use this. Just enter a Japanese webpage’s url and this website will generate a new page with popup definitions.

This also has a way to make your own vocabulary lists from a webpage

Add Ruby

This site will give you pronunciations for text or web addresses by adding the rubi (furigana) for compounds.

GENERAL RESEARCH

PSU Library subscribes to JAPAN KNOWLEDGE Database.

•You need to login using your psu id (use the VPN LIAS setting for off-campus access).  Ask a reference librarian for help. Probably the best single collection of online dictionaries.  Includes:Encyclopedia Nipponica, Kodansha Encyclopedia of Japan, Progressive Japanese-English/English-Japanese Dictionaries, Gendai Yogo No Kiso Chishiki, Nihon Jinmei Daijiten.
